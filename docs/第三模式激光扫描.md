# 第三模式激光扫描

## 配置和界面

- `ModeConfig.toml`：`strategy_name = 3`，重启生效。
- `ReadDataConfig.toml`：`min_swing_pulse = 0`、`max_swing_pulse = 3000` 定义扫描端点，起点也作为启动回零位置。
- `lidar_scan_speed = 25`：扫描和回零共用速度，单位mm/s。主界面速度输入框下方的 **Save setting** 保存此值，运行中通过现有控制队列更新。
- `SprayConfig.toml`：`spray_pos_tolerance` 用于四轴同步校验及端点到位判定。
- `ReadDataConfig.toml`：本项目配置 `pulse_to_mm = 1`，代码读取配置，不按模式覆盖。
- `swing_threshold` 保留旧配置，本实现以定位公差判断端点，不再用此值截断扫描。

## 执行过程

1. 等待采数进程首次返回激光状态，避免激光尚未连好就开始运动。
2. PLC总使能开启且伺服正常时检查四轴位置。已在任一端点则等待扫描；停在中间则先回起点，回零期间不采数。
3. 收到 `Status.bit1` 工件到达激光位信号后，从当前端点扫到另一端。
4. 到端点后结束本趟。到位信号持续为1不重复扫描；信号撤销再到位后扫描下一趟。
5. 当前只驱动四个激光轴，其他轴保持反馈位置、速度0；四激光轴 `Status` 永远为0。
6. 手补位、喷涂位、工件放行尚未实现，发送公共状态只提供伺服正常位，不自动设置放行位。

## 位置与采数

使用 `MachineAxisMap.LIDAR_AXIS_MAP` 的201～204四轴反馈：

`max(四轴位置) - min(四轴位置) <= spray_pos_tolerance`

满足条件时，`pulse = floor(sum(四轴位置) / 4)`。
PLC到采数仍使用 `{pulse, fifo, status}`；`fifo` 沿用位置换算，第三模式不按FIFO递增划分工件。
扫描发布 `moving_forward/moving_reverse`，回零、等待和完成发布 `stopped`，异常发布 `error`。
通信断开沿用已有 `pulse=-999` 通知。

Z使用 `pulse - min_swing_pulse`，正反向共用固定原点；不使用链条回绕，也不在保存时重复减去点云最小Z。
同一位置只采集一次，结束判定同时检查端点位置和PLC停止状态，避免端点附近形成重复小段。
点云仍按整趟、所有方向合包交付；PLC暂存最新整趟包，后续工位处理需继续开发。

## 异常处理

四轴不同步、位置越界、扫描中撤销使能/工件到位、PLC通信中断或激光采集异常时，本趟作废。
PLC异常锁存并输出零速度，处理后重新启动软件；正常状态包不会清除同批次已出现的异常。
激光断连在阻塞重连前立即通知PLC，采数端不会从同一趟的中间重新接入并交付残缺工件。
