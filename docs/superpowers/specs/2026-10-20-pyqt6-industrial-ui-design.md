# PyQt6 工业控制中心界面改造设计

## 目标

将现有 wxPython 界面替换为深色工业风的 PyQt6 控制中心。界面采用“左侧工作台导航、中间三维工作区、右侧生产控制、底部任务与事件流”的布局；设备参数改为主界面页签，不再使用独立配置弹窗。

本次改造的成功标准是：保留既有采数、点云处理、柜体识别、分枪、运动规划、PLC 通讯与设备配置行为，同时获得可视化层级清晰、适配现场大屏的专业三维检测软件体验。

## 范围与边界

### 保持不变

- `control/` 的进程、队列与 PLC 通讯协议。
- `model/` 的策略选择、点云处理、柜体特征提取、分枪与运动规划逻辑。
- 现有配置读取、保存与实时下发语义。
- 现有的设备控制能力：启动、停止、扫描速度、左右侧机、左右升降机、设备参数保存。

### 需要替换或新增

- `view/MainFrame.py`：由 wxPython 主窗体替换为 PyQt6 控制中心。
- `view/MachineConfigFrame.py`：其表单能力转入“设备配置”工作区页签；配置读写仍复用控制层入口。
- `model/plot/PointCloudCanvas.py`：迁为可嵌入 PyQt6 的 `QOpenGLWidget`（或以独立 Qt 适配器封装），保持点云数据输入契约。
- UI 桥接层：将后台进程队列与回调转换为 Qt `Signal/Slot`，确保所有控件更新均在主线程执行。
- 应用启动入口：初始化 `QApplication`、主题、主窗口与桥接对象。

## 信息架构

### 实时控制页

- 中央：点云、柜体特征、喷涂路径的三维工作区；提供复位视角、缩放、显示层切换等视图操作。
- 右侧：输送链状态、PLC/激光/伺服联锁、当前工艺阶段、已启用喷枪数量、启动与安全停止。
- 底部：当前任务进度、最新事件流和报警摘要。

### 点云采集页

- 采集状态、当前点数、扫描位置与速度。
- 点云图层开关：原始点云、已分割工件、外框、内框、挂具、喷涂路径。
- 与现有处理队列保持相同数据来源，不在 UI 层重做算法。

### 喷涂任务页

- 当前工件、策略名称、识别结果、分枪结果与规划阶段。
- 展示 `xn_side` 的当前喷涂状态和执行进度。

### 设备配置页

- 以页签区分设备或工件类型，例如 xn_side 柜体配置与平板配置。
- 字段定义、整数校验、读取/保存和实时下发复用既有控制函数。
- 仅对当前策略显示适用字段；保存失败时在页内给出明确错误信息。

### 运行记录页

- 可筛选的状态、告警和通讯日志。
- 不替代原始日志文件，仅作为运行期只读观察面板。

## UI 架构

```
PyQt6 MainWindow
├── NavigationRail
├── StackedWorkspace
│   ├── RealtimeControlPage
│   ├── AcquisitionPage
│   ├── SprayTaskPage
│   ├── DeviceConfigPage
│   └── RuntimeLogPage
├── QtPointCloudView (QOpenGLWidget)
└── UiBridge (QTimer + Signal/Slot)
       └── existing control queues / callbacks / config services
```

`UiBridge` 是唯一读取后台状态并更新界面的对象。它将原有状态、队列消息和异常转换为结构化 UI 信号，避免后台线程直接调用 Qt 控件。业务层不引用 PyQt6，确保现场控制逻辑与视图实现解耦。

## 视觉规范

- 深蓝黑背景，薄边框和低对比度网格构成工业控制台基底。
- 青色表示点云、在线与正常状态；橙色表示模型、路径与当前焦点；红色仅用于停止、告警与联锁失败。
- 使用卡片、状态胶囊、稀疏分割线和明确数字层级，不使用大面积渐变或装饰性图标堆叠。
- 中央 3D 视图优先，控制信息不遮挡点云工作区。

## 数据流与错误处理

1. 既有控制/处理进程继续向其原有队列写入状态和数据。
2. `UiBridge` 定时、非阻塞地读取可显示的状态摘要，发射 Qt 信号。
3. 页面通过槽函数刷新文本、状态灯、进度条和点云视图。
4. UI 控制操作转为既有控制命令或配置保存调用；失败时保留当前页面状态，并显示操作、原因与建议。
5. PLC、激光或伺服联锁异常时，右侧状态区优先显示；安全停止入口始终可用。

## 分阶段实施与验证

1. 建立 PyQt6 应用骨架、主题和控制中心布局；验证能启动且不触碰业务进程。
2. 接入原有启动/停止、扫描位置、速度、设备按钮和日志；逐项验证原行为保持。
3. 迁移设备配置为页签表单；验证读取、整数校验、保存和实时下发。
4. 迁移点云画布并接入图层显示；验证点云刷新、相机操作和资源释放。
5. 接入任务、分枪与联锁状态；做策略模式、无设备、通讯异常与安全停止回归。

## 非目标

- 不修改喷涂路径算法、枪组分配规则或 `strategy_name` 语义。
- 不改写 PLC 报文格式、控制时序或后台进程拓扑。
- 不在本次引入云端服务、用户权限系统或新的数据库。
